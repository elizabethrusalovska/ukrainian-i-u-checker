
# І чи И? — правописний аналізатор української мови


## Онлайн-версія застосунку

Спробувати правописний аналізатор можна за посиланням:

[І чи И? — перевірка українського правопису](https://ukrainian-i-u-checker.onrender.com)

Застосунок розроблено мовою Python із використанням
Gradio та опубліковано на платформі Render.
Лабораторна робота з комп'ютерної лінгвістики.

**Тема:** Вживання літер І/И на початку українських слів.

**Авторка:** Єлизавета Поліщук  
**Спеціальність:** Прикладна лінгвістика  
**Курс:** 2

## Мета роботи

Розробити програму для аналізу вживання літер
«і» та «и» на початку українських слів.

## Можливості застосунку

- Пошук слів із початковими і/и.
- Виявлення потенційних орфографічних помилок.
- Розпізнавання винятків і варіантних написань.
- Підсвічування результатів різними кольорами.
- Виведення пояснень правописних правил.
- Формування тексту із запропонованими виправленнями.
- Обробка некоректного введення.

## Використані технології

- Python — реалізація алгоритму.
- Regular Expressions (re) — пошук слів.
- Gradio — графічний вебінтерфейс.
- pytest — автоматичне тестування.

## Алгоритм роботи

1. Отримання тексту від користувача.
2. Перевірка коректності введених даних.
3. Пошук слів за допомогою регулярних виразів.
4. Відбір слів із початковими і/и.
5. Перевірка правописних правил та винятків.
6. Класифікація результатів.
7. Формування пропозицій виправлення.
8. Виведення результатів через Gradio.

## Структура проєкту

- `spelling_checker.py` — реалізація алгоритму.
- `app.py` — вебінтерфейс.
- `samples/` — тестові тексти.
- `tests/` — автоматичні тести.
- `requirements.txt` — залежності.
- `pytest.ini` — налаштування тестування.

## Запуск програми

Встановити бібліотеки:

```bash
python -m pip install -r requirements.txt
```

Запустити вебзастосунок:

```bash
python app.py
```

Відкрити локальне посилання Gradio у браузері.

## Автоматичне тестування

Для запуску тестів виконати:

```bash
python -m pytest
```

## Обмеження

Програма реалізує правиловий алгоритм і не
використовує повний орфографічний словник.

Запропоновані виправлення потребують перевірки,
особливо для власних назв та рідковживаних слів.

## Лінгвістична основа

Український правопис, § 2:
«Уживання І, И на початку слова».
